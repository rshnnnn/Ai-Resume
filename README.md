🤖 AI Interview Assistant

An AI-powered full-stack web application that helps job seekers prepare for interviews by analyzing their resume and job description to generate personalized interview reports. The application leverages Google's Gemini AI to provide technical and behavioral interview questions, skill gap analysis, a preparation roadmap, and dynamically generated resume PDFs.

✨ Features 📄 Upload and analyze PDF resumes 🤖 AI-generated interview reports using Google Gemini AI 💯 Resume-to-job match score analysis 💻 Personalized technical interview questions with model answers 🗣️ Behavioral interview questions with interview intent 🎯 Skill gap analysis with severity levels 🗓️ AI-generated preparation roadmap 📑 Dynamic resume PDF generation using Puppeteer 🔐 Secure user authentication and protected routes 📂 Interview report history and retrieval 📱 Responsive and modern user interface 🛠️ Tech Stack

Frontend

React.js React Router Context API Custom Hooks Axios SCSS

Backend

Node.js Express.js MongoDB Mongoose Multer PDF-Parse Puppeteer Google Gemini AI API 🚀 How It Works Upload your resume (PDF). Enter your self-description and target job description. The application extracts resume content and sends it to Gemini AI. AI generates: Match Score Technical Questions Behavioral Questions Skill Gap Analysis Personalized Preparation Plan Users can view reports and download an AI-generated resume PDF.
